The knight's perfect tour, challenge chess with linear optimization

Created in July 12, 2026

2026   ·   game   chessboard   knight   puzzle   tour   ·   modelling

Image by servet photograph retrieved from Unsplash

The Knight’s Tour is a classic mathematical and chess problem that consists of moving a knight on an $n \times n$ chessboard so that it visits each and every square exactly once.

There are two main variants of this problem:

  • Closed tour: The knight ends on a square that is one move away from the starting square, forming a complete cycle that could repeat indefinitely.
  • Open tour: The knight visits all squares, but the final square does not allow returning to the starting square in a single move.

This problem has fascinated mathematicians for centuries, from the celebrated Leonhard Euler in the 18th century to modern research in graph theory and Operations Research.

Do you dare to find a complete closed path before checking the solution and its mathematical modeling?

The Knight’s Tour can be formulated as a Traveling Salesperson Problem on a directed graph, do you dare to try it?

To solve the Knight’s Tour systematically, we can use an integer linear optimization model based on the Miller-Tucker-Zemlin subtour elimination formulation (Miller et al., 1960).

Index sets

  • \(\mathcal{V} = \{1, 2, \dots, N\}\): Set of $N = n^2$ board squares ($N = 64$ for an $8 \times 8$ board).
  • \(\mathcal{A} \subset \mathcal{V} \times \mathcal{V}\): Set of directed arcs $(i,j)$ representing valid knight moves between square $i$ and square $j$.

Parameters

  • \(N\): Total number of board squares ($N = 64$).

Decision variables

  • \(x_{ij} = 1\) if the knight moves directly from square $i \in \mathcal{V}$ to square $j \in \mathcal{V}$, and $0$ otherwise.
  • \(u_i \in \{1, \dots, N\}\): Continuous auxiliary variable indicating the visiting order of square $i \in \mathcal{V}$ in the tour sequence.

Since this is a feasibility problem (finding a Hamiltonian cycle in the knight’s movement graph), the objective function is arbitrary:

Objective function

\[\min z = 0\]

We now define the model constraints:

Exactly one outgoing move per square:

\[\displaystyle \sum_{j : (i,j) \in \mathcal{A}} x_{ij} = 1 \quad \forall i \in \mathcal{V}\]

Exactly one incoming move per square:

\[\displaystyle \sum_{i : (i,j) \in \mathcal{A}} x_{ij} = 1 \quad \forall j \in \mathcal{V}\]

Subtour elimination (MTZ Formulation):

\[u_i - u_j + N x_{ij} \leqslant N - 1 \quad \forall (i,j) \in \mathcal{A}, \; i \neq 1, \; j \neq 1\]

Variable domains:

\[u_1 = 1\] \[1 \leqslant u_i \leqslant N \quad \forall i \in \mathcal{V}\] \[x_{ij} \in \{0,1\} \quad \forall (i,j) \in \mathcal{A}\]
